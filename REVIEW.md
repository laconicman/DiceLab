# Review Guidelines

## Critical Areas

- Flag raw `categoryBitMask`/`collisionBitMask`/`contactTestBitMask` literals
  under `DiceLab/Features/` — use `DiceLab/Features/Roll/PhysicsCategory.swift`.
- Reject `SCNNode.categoryBitMask` assignments under `DiceLab/` — render-only,
  never affects physics; the ancestors carried this bug.
- Reject `@Observable`/UI mutations in `SCNPhysicsContactDelegate` methods under
  `DiceLab/Features/` unless main-actor dispatched — callbacks run off-main.

## Conventions

- Require `DiceLab/Documentation.docc/Design.md` to be updated in the same
  commit as any diff that changes a decision recorded there.
- Flag comments under `DiceLab/` that restate the line they annotate —
  comments explain *why* (learning project), not *what*.
- Flag physics constants (impulse magnitudes, positions, sizes) written as
  inline literals under `DiceLab/Features/`; they belong as named constants.
- Reject `import SceneKit`/`import RealityKit` under `DiceLab/Model/` — the
  model layer staying engine-free is what made the M7 port a controller swap.

## Anti-patterns to Flag

- Reject force-unwrapped optional assets (`UIImage(...)!`) under `DiceLab/` —
  the ancestors did this; require `guard let` with a fallback.
- Reject commented-out code blocks longer than 2 lines under `DiceLab/` —
  delete instead; git holds history.

## Ignore

- Ignore `DiceLab.xcodeproj/` — generated by XcodeGen; review `project.yml`
  instead.
- Ignore `DiceLab/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` —
  generated by `scripts/make-icon.swift`; review the script instead.
- Ignore `DiceLab/Documentation.docc/` — review for accuracy, not style.
